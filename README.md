# shuo-jia-jietu
说“甲”解图网页小游戏

大班语言活动《说“甲”解图》里用的甲骨文拼摆小游戏。**一个文件就能玩，不用联网、不用装软件、不用服务器**：双击 `index.html` 就能打开。

## 怎么玩

- 下方是甲骨文部件盘，**点一下部件**（或者把它拖进框里）就能放进拼字台的两个框。
- 两个符号拼对了：它们会合拢，变成一个全新的符号，右边接着出现它代表的生活画面和语音解释。
- 拼错了：界面会轻轻提示“再试试”，两个符号自己回到原位，可以重新来。
- 每拼出一个，右上角亮一格；七格全亮，就是这一轮的成绩。
- 右上角 🔊 开关声音，↺ 回到开始。

| 部件 | 拼出的符号 | 意思 |
| --- | --- | --- |
| 人 ＋ 木 | 休 | 一个人靠在树旁，正在休息 |
| 木 ＋ 木 | 林 | 两棵树并排站在一起，就是树林 |
| 木 ＋ 火 | 焚 | 火烧着了树木 |
| 月 ＋ 日 | 明 | 太阳和月亮都亮亮的，所以很明亮 |
| 人 ＋ 人 | 从 | 一个人跟在另一个人的后面走 |
| 女 ＋ 子 | 好 | 妈妈和孩子亲亲热热在一起 |
| 宀 ＋ 豕 | 家 | 屋子里养着小猪，有屋有猪就是家 |

## 设备

支持手指拖拽和点击，平板、手机、触摸一体机都能直接玩；电脑上用浏览器打开也行。

## 说明

- 页面里的甲骨符号字形参考“殷契文渊”等公开的甲骨文字形资料绘制。
- 每组的象形小动画以 base64 内嵌在页面里，所以文件比较大（约 12 MB）——这是为了在不能联网的教室电脑上也一定能打开。
